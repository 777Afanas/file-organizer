🗂️ File Organizer CLI

Сучасний CLI-інструмент на Node.js для аналізу, організації та очищення директорій. Проєкт дозволяє збирати статистику, знаходити дублікати, сортувати файли за категоріями та безпечно видаляти застарілі дані. Побудований з використанням сучасної архітектури на базі EventEmitter та Streams для ефективної обробки великих файлів.

🚀 Встановлення та запуск

Впевніться, що у вас встановлено Node.js (рекомендовано v18+).

**1. Склонуйте репозиторій або перейдіть у папку з проєктом:**

git clone <repository-url>
cd file-organizer

**2. Встановіть залежності (commander, chalk та dev-залежності):**

npm install

📝 Про проєкт

File Organizer CLI — це консольна утиліта, створена для допомоги користувачам у наведенні ладу у файловій системі без перевантаження ресурсів комп'ютера.

Додаток дозволяє:

Переглядати зведену статистику по директорії (кількість, розміри, типи файлів, найстаріші/найновіші файли).

Знаходити файли з абсолютно однаковим вмістом завдяки обчисленню криптографічних хешів.

Автоматично сортувати файли по категоріях (Documents, Images, Archives, Code, Videos, Other) з перенесенням у цільову директорію.

Ефективно копіювати великі файли (≥ 10 MB) завдяки використанню потоків (Streams).

Здійснювати пошук та видалення файлів, старіших за вказану кількість днів, із попереднім переглядом змін для запобігання випадковій втраті даних.

⚡ Основні функції

1. Аналіз директорії (scan)

Збір статистики: Рекурсивне сканування обраної директорії з виводом даних про розширення файлів, їх загальну кількість та сумарний розмір.

Віковий аналіз: Визначення найстаріших файлів у директорії.

2. Пошук дублікатів (duplicates)

Розумне порівняння: Попереднє групування файлів за розміром задля економії ресурсів, після чого застосовується точне порівняння за допомогою SHA-256 хешування.

Підрахунок економії: Вивід інформації про обсяг пам'яті, який можна звільнити, видаливши копії.

3. Організація файлів (organize)

Автоматичне сортування: Розподіл файлів із вихідної папки до нової структурованої директорії (по категоріях).

Оптимізація пам'яті: Використання fs.createReadStream та fs.createWriteStream для безпечного копіювання важких файлів без перевитрати оперативної пам'яті.

4. Очищення старих даних (cleanup)

Безпечний режим (Dry Run): За замовчуванням команда лише виводить список файлів, що підлягають видаленню, не видаляючи їх фізично.

Фактичне видалення: Здійснюється лише за наявності спеціального прапорця підтвердження (--confirm).

🛠️ Технологічний стек

Платформа: Node.js (ES Modules)

Маршрутизація команд: Commander.js

Стилізація консолі: Chalk

Архітектура: EventEmitter (кожна команда реалізована як окремий клас, що генерує події прогресу)

Робота з файловою системою: Модуль fs (вкл. Streams) та crypto (для хешування)

💻 Послідовність тестування (NPM Scripts)

У проєкті вже налаштовані зручні скрипти для швидкого тестування функціоналу у спеціально створеній папці ./test-directory.

1. (При бажанні) Запуск генератора тестових даних

Виконайте в терміналі команду:

node generate-test-files.js

**або через npm: npm run generate-test**

Обґрунтування: Це підтвердить, що скрипт написаний без синтаксичних помилок і коректно виконує всі асинхронні операції з файловою системою, створюючи набір необхідних файлів для перевірки всіх функцій.

2. Виконання команд

Після генерації тестового середовища виконайте наступні команди:

npm run dev:scan — Запускає сканування та виводить детальну статистику папки.

npm run dev:duplicates — Знаходить групи однакових файлів.

npm run dev:organize — Створює папку ./Organized та переносить туди файли, сортуючи їх по категоріях.

npm run dev:cleanup — Шукає файли старіші за 90 днів у режимі попереднього перегляду (файли НЕ видаляються).

npm run dev:cleanup:confirm — Виконує безповоротне видалення знайдених старих файлів (застосовується прапорець --confirm).

(Також ви можете використовувати ці команди вручну, викликаючи node file-organizer.js <command> [options])
